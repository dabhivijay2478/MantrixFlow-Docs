Connections are reusable encrypted credentials. PostgreSQL, MySQL, Airtable,
and ClickHouse are available as both sources and destinations. HubSpot and
Stripe are available as sources. Asana supports workspace/project scoping,
and Notion supports shared data-source discovery with dlt-backed incremental
extraction. Linear is a Beta source with team/project scope and eight
supported resources. Zendesk is a Beta, OAuth-only source with 13 Zendesk
Support resources.

## Create a source connection

1. Open **Connections**.
2. Click **+ New Connection**.
3. Set the role to **Source**.
4. Choose **PostgreSQL**, **MySQL**, **Airtable**, **ClickHouse**, **Asana**, **Linear**, **Notion**, **Zendesk**, **HubSpot**, or **Stripe**.
5. Fill the connector-specific fields. Airtable and Asana use Personal Access
   Tokens; Linear uses a Personal API Key; Notion uses an internal integration
   token; Zendesk uses OAuth; HubSpot uses a private app access token.
6. Click **Test Connection**.
7. Save after the test succeeds.

## Create a destination connection

1. Open **Connections**.
2. Click **+ New Connection**.
3. Set the role to **Destination**.
4. Choose **PostgreSQL**, **MySQL**, **Airtable**, or **ClickHouse**.
5. Fill the destination database credentials.
6. Click **Test Connection**.
7. Save after the test succeeds.

Database destination users need write access to existing tables and permission
to create or reconcile tables only when using the explicit setup action.
Airtable destinations need an existing base/table, writable mapped fields, and
record read/write access.

## Network access

If your database is hosted behind a provider firewall, allow traffic from the MantrixFlow runtime before testing the connection. See [Private database access](/connections/private-database-access).
