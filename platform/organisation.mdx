---

An organisation is the top-level container for your team, connections, and pipelines. All resources belong to an organisation.

## Creating an Organisation

When you sign up, you may be prompted to create an organisation. Enter a name and optionally a slug. The organisation ID (UUID) is used in API requests.

## Organisation Settings

- **Name** — Display name for the organisation.
- **Slug** — URL-friendly identifier (e.g. for subdomains or vanity URLs).
- **Current organisation** — If you belong to multiple organisations, you can switch the current one. The current organisation is used for API requests and the UI.

## Switching Organisations

Use the organisation switcher in the sidebar or header to change the current organisation. All connections and pipelines are scoped to the organisation.
