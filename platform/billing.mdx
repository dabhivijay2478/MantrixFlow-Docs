MantrixFlow billing is typically based on usage. Check [cloud.mantrixflow.com](https://cloud.mantrixflow.com) for current pricing.

## Billing Model

Common factors:

- **Rows synced** — Number of rows transferred per month.
- **Pipeline runs** — Number of sync runs per month.
- **Connections** — Number of active connections.
- **Team members** — Number of users in the organisation.

## Viewing Usage

Go to Organisation Settings → Billing to see your current usage and plan. Usage is updated periodically.

## Upgrading or Changing Plan

Use the billing settings to upgrade, downgrade, or change your plan. Changes may take effect at the next billing cycle.
