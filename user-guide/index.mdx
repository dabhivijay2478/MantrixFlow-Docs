This guide follows the live workspace flow.

## Main workflow

1. Create PostgreSQL source and destination connections.
2. Create a pipeline shell with a name and source connection.
3. Configure the Source node.
4. Configure the Destination node.
5. Save and run manually.
6. Review run history.
7. Add an Incremental schedule only after validation.
