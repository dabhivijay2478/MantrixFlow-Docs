This guide follows the live tabbed pipeline workspace. It does not describe the
removed canvas editor.

## Main workflow

1. Create source and destination connections.
2. Create and open a pipeline.
3. Configure streams in **Source**.
4. Add a target in **Destinations**.
5. Create and publish destination-owned SQL in **Transformations**.
6. Assign output tables and Upsert keys in the destination editor.
7. Validate in **Overview** and click **Run all**.
8. Review **Runs**.
9. Add automation in **Settings** after validation.
