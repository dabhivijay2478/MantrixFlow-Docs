This guide matches the **current workspace shell** in the MantrixFlow app (sidebar order and routes as implemented in the product).

**Workspace sidebar (typical)**

1. **Dashboard** — `/workspace`
2. **Connections** — `/workspace/connections` (sources and destinations; **+ New Connection** starts at `/workspace/connections/new`, optional `?role=destination`)
3. **Data Pipelines** — `/workspace/data-pipelines`
4. **Activity Log** — `/workspace/activity`
5. **Settings** — `/workspace/settings` (includes **Organization** for the active org)
6. **Team** — `/workspace/team` (shown for **Owner** and **Admin** roles)

**Terminology**

| Concept | Where it lives in the app |
|--------|---------------------------|
| Source / destination credentials | **Connections** (`/workspace/connections`) |
| Table/query explorer for a saved connection | Often `/workspace/data-sources/[id]/query` (opened from connection actions—URLs keep the **data-sources** segment even though the main list is under **Connections**) |
| Sync configuration & canvas | **Data Pipelines** → **Open Builder** (`/workspace/data-pipelines/[id]/builder`) |
| Run metrics & run history | Pipeline detail (`/workspace/data-pipelines/[id]`) |
| Org-wide audit events | **Activity Log** (`/workspace/activity`) |
| Pipeline branch | A **branch** on the builder canvas (transform → destination path)—not a separate Git/environment screen |

Screenshots in this section are **real captures** from a logged-in workspace. Redact or replace them before publishing if they expose hostnames, emails, or internal IDs.
