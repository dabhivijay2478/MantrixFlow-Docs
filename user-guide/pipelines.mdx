---
title: Pipelines & run history
description: Create pipelines, open the visual builder, monitor runs, status, and errors on the pipeline detail page.
---

Key routes:

- List: `/workspace/data-pipelines`
- Create: `/workspace/data-pipelines/new`
- Builder (canvas): `/workspace/data-pipelines/[pipelineId]/builder`
- Detail (runs, tabs): `/workspace/data-pipelines/[pipelineId]`

## Pipeline list

Open **Data Pipelines** in the sidebar (`/workspace/data-pipelines`). The page title may read **Pipelines**. Filter by **All**, **Running**, **Failed**, or **Scheduled**. Search narrows the list. Each card shows name, last status, source connector, branch or destination labels when present, and last run time.

<img src="/images/user-guide/ug-pipelines-list.png" alt="Pipelines list" className="rounded-lg border border-zinc-700/50 max-w-full h-auto w-auto block my-4 dark:border-zinc-600/60" loading="lazy" />

## Create a pipeline

1. Click **+ New Pipeline**.
2. Enter a **Pipeline name** and select a **Source connection**.
3. Click **Create & open canvas** to land in the builder (you configure transforms and destinations on the canvas).

<img src="/images/user-guide/ug-new-pipeline-form.png" alt="Create pipeline form" className="rounded-lg border border-zinc-700/50 max-w-full h-auto w-auto block my-4 dark:border-zinc-600/60" loading="lazy" />

## Open the builder (edit pipeline graph)

- Click the pipeline row to open the canvas, or use **⋯** → **Open Builder**.

The canvas shows the **source** node, optional **transform** nodes, and **destination** nodes with listen/run states and quick actions (**Add transform**, **Add emitter (destination)**, **Run pipeline**, etc.).

<img src="/images/user-guide/ug-pipeline-builder-branches.png" alt="Pipeline builder — branches on canvas" className="rounded-lg border border-zinc-700/50 max-w-full h-auto w-auto block my-4 dark:border-zinc-600/60" loading="lazy" />

## Run history, status, and errors

Open the pipeline’s **detail** page (not only the builder). You will see:

- Summary metrics (rows processed, success/fail counts, last sync time).
- Tabs such as **Run History**, **Code**, **Explore**, **Incoming/Outgoing Data**, **Configuration**, **Settings**.
- **Recent runs** with status, trigger, rows written, failures, duration.

If the source or destination connection is disconnected, a **banner** explains that the pipeline cannot run until you reconnect under **Connections**.

<img src="/images/user-guide/ug-pipeline-detail-runs.png" alt="Pipeline detail — run history and warning banner" className="rounded-lg border border-zinc-700/50 max-w-full h-auto w-auto block my-4 dark:border-zinc-600/60" loading="lazy" />

## Row actions: run and delete

Use **Run now** on the list to trigger a manual run. **⋯** opens:

- **Open Builder**
- **Run Now**
- **Delete** (destructive; confirm in the modal)

<img src="/images/user-guide/ug-pipeline-row-menu.png" alt="Pipeline row overflow menu" className="rounded-lg border border-zinc-700/50 max-w-full h-auto w-auto block my-4 dark:border-zinc-600/60" loading="lazy" />

<img src="/images/user-guide/ug-pipeline-delete-confirm.png" alt="Delete pipeline confirmation" className="rounded-lg border border-zinc-700/50 max-w-full h-auto w-auto block my-4 dark:border-zinc-600/60" loading="lazy" />

Cancel the dialog if you only wanted to inspect the warning; deletion is permanent.

## Edit metadata vs graph

- **Graph** (streams, branches, transforms, destinations): **Open Builder** and **Save** on the canvas toolbar where applicable.
- **Schedule, sync options, detail tabs**: use the pipeline **detail** page tabs (**Configuration** / **Settings**) as implemented for your org’s API version.
