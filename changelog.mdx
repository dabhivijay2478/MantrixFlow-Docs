## Stripe source Beta

- Stripe is now documented as an available Beta source connector.
- The Beta exposes 34 tested streams and hides 29 feature-gated streams.
- Connection testing, empty-stream handling, destination table setup,
  PostgreSQL delivery, and idempotent reruns are documented.
- Beta error reports should include the run ID, stream, timestamp, mode, and
  displayed error code, but never credentials.

## Current alignment

- Public docs describe live PostgreSQL workflows and the Stripe source Beta.
- Navigation exposes live connector pages and clearly labeled Beta pages.
- Pipeline docs now center the real Source node and Destination node builder flow.
- Transformation guidance now points to destination-scoped Normalisation and the SQL Layer.
- Sync docs now clarify that schedules are for Incremental destinations.
- Destination docs now state that final tables must already exist before delivery.

## Removed from public workflow docs

- Non-live connector setup instructions
- Canvas nodes that are not active in the current public builder flow
- Log-based change capture setup pages from navigation
- Destructive or insert-only write modes as available choices
- Destination table auto-creation claims
