---
title: Transformation rules
description: "The current transformation model: destination-scoped Normalisation plus SQL models."
---

Transformations are owned by a destination and configured in the **Destination** panel.

| Layer | Location | Purpose |
| --- | --- | --- |
| Normalisation | Destination panel | Rename and cast columns before the SQL model |
| SQL Layer | Destination panel | SQL model that selects final output columns |

Use [Normalisation](/pipelines/normalisation) for small structural changes such as renaming or casting a column.

Use the [SQL Layer](/pipelines/dbt-layer) for filtering, derived fields, JSON extraction, joins, aggregations, and final output selection.

Validate and preview the SQL model before saving it. The saved model output must match the pre-created destination table.
