## What you can do

- **Connect** — Databases, warehouses, and SaaS (PostgreSQL, Snowflake, Shopify, Stripe, and more).
- **Pipeline builder** — Visual graph: source → optional Python transform → one or more destinations.
- **Sync** — Full load, incremental, and CDC where the connector supports it.
- **Operate** — Run history, activity log, schedules, and org / team settings in the app.
