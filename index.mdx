MANTrixFlow is a data integration platform that helps you connect your data sources to your destinations. You can build pipelines that sync data from databases, cloud warehouses, SaaS applications, and more into your analytics stack.

This documentation is organised into these areas:

1. **User guide** — End-to-end workflows in the live app (connections, pipelines, transforms, organisations, activity)—with **screenshots** captured from the product.
2. **Getting Started** — Create your account and run your first pipeline in under 10 minutes.
3. **Connections** — Guides for every source and destination connector, including setup steps and configuration details.
4. **Pipelines and Platform** — Sync modes, transformations reference, API, and billing.

## What You Can Do

- **Connect** — Add source connections for PostgreSQL, MySQL, MongoDB, Snowflake, BigQuery, Shopify, Stripe, HubSpot, and many more.
- **Build Pipelines** — Link a source to a destination, choose streams, set sync modes, and configure column mapping.
- **Sync** — Run full sync, incremental sync, or CDC (change data capture) depending on your source and use case.
- **Transform** — Apply rename, cast, filter, and other transformation rules before data reaches the destination.
- **Automate** — Schedule pipelines to run automatically at intervals you define.
