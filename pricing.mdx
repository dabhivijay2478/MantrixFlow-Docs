## Usage-based pricing

Usage pricing applies on top of your plan as traffic increases:

- `$5 / 1M rows`
- `$0.002 / 1K API calls`

Included row usage is a monthly allowance. If a workspace uses its monthly rows in the first 10 days, additional delivered rows for the rest of that billing cycle count as overage. See [Billing Breakdown](/billing-breakdown) for the upgrade/downgrade and overage calculation model.

## Plan details

### Starter

Use Starter when you are validating data shape, testing connectors, or building a first internal workflow.

- 3 Pipelines
- 10K rows/month
- API + SDK (limited)
- 1K API calls/day
- Basic logs

### Growth

Use Growth when your team needs more scheduled automation and enough throughput for startup-scale workloads.

- 20 Pipelines
- 1M rows/month
- API + SDK access
- 50K API calls/day
- Scheduling + Webhooks
- Standard logs

### Pro

Use Pro when you need more throughput, real-time pipeline support, and advanced operational tooling.

- 50+ Pipelines
- 10M+ rows/month
- High-speed processing
- 500K API calls/day
- Real-time pipelines
- AI agents (beta)
- Advanced logs + retry

### Enterprise

Use Enterprise when you need dedicated architecture, custom onboarding, or formal operational commitments.

- Unlimited pipelines
- Dedicated infra
- MCP Server access
- Multi-tenant support
- SLA + uptime guarantee
- Custom connectors
