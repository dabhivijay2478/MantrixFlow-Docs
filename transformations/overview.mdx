The transform type depends on the pipeline source:

| Pipeline type | Transform | Where to write it |
| --- | --- | --- |
| PostgreSQL-to-PostgreSQL | SQL `SELECT` using `{{ source }}` | SQL editor in the Transform panel |
| SaaS sources (Shopify, Stripe, HubSpot, GitHub, Notion) | Python `transform(record)` function | Python editor in the Transform panel |

There is no visual rename, cast wizard, or point-and-click mapping screen. All shaping is done in SQL or Python directly.

## What is live in the Transform panel today

- Branch label and source table selector
- **SQL editor** for PostgreSQL-to-PostgreSQL pipelines
- **Python editor** for SaaS source pipelines
- **Load Example** menu (SaaS sources only)
- **Preview** using live sample rows from the source
- **Save** action
- Separate **Filter** node (SQL `WHERE` clause or Python expression)

## Fast path — PostgreSQL-to-Postgres pipeline

1. Select the source table in **Source Configuration**.
2. Open the **Transform** panel and write a SQL `SELECT` using `{{ source }}`.
3. Click **Preview** to confirm the output columns.
4. Save, configure the destination, and run manually.

## Fast path — SaaS source pipeline

1. Select the resource in **Source Configuration**.
2. Open the **Transform** panel and write a `def transform(record):` function.
3. Click **Preview with sample data** to confirm the output.
4. Save, configure the destination, and run manually.
