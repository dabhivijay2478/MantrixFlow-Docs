The **Transform** panel is the record-shaping surface inside the pipeline builder. Each branch has its own transform. The editor type that appears depends on the source:

- **PostgreSQL source → PostgreSQL destination**: SQL editor
- **SaaS source (Shopify, Stripe, HubSpot, GitHub, Notion)**: Python editor

---

## SQL editor — PostgreSQL-to-PostgreSQL pipelines

### What the panel shows

- Branch label
- Source table selector
- SQL editor (write a `SELECT` using `{{ source }}`)
- **Preview** button
- **Save** button

### How to use it

<Steps>
  <Step title="Open the Transform panel">
    In the builder, click the **Transform** node on the branch you want to configure.
  </Step>
  <Step title="Write your SELECT">
    Use `{{ source }}` as the table reference. MantrixFlow substitutes the actual stream at run time.

    ```sql
    SELECT
      id,
      LOWER(email)                    AS email,
      first_name || ' ' || last_name  AS full_name,
      amount_cents::NUMERIC / 100     AS amount_usd,
      created_at::TIMESTAMPTZ         AS created_at
    FROM {{ source }}
    WHERE is_deleted = false
    ```
  </Step>
  <Step title="Preview">
    Click **Preview** to fetch live sample rows and confirm the output column names and types.
  </Step>
  <Step title="Save">
    Click **Save**. The transform is now part of the pipeline configuration.
  </Step>
</Steps>

For the full SQL pattern library see [Postgres-to-Postgres examples](/example/postgres-to-postgres).

## Python editor — SaaS source pipelines

### What the panel shows

- Branch label
- Resource selector
- Python editor (`def transform(record):`)
- **Load Example** menu
- **Preview with sample data** button
- **Save Script** button

### Required function shape

```python
def transform(record):
    return record
```

Return a `dict` to pass the record through. Return `None` to drop it. Do not use external I/O inside the function.

### How to use it

<Steps>
  <Step title="Open the Transform panel">
    Click the **Transform** node on the branch.
  </Step>
  <Step title="Load a starter example (optional)">
    Click **Load Example** to start from a pre-built pattern for the current source (Stripe, Shopify, HubSpot, etc.).
  </Step>
  <Step title="Edit the function">
    Shape the record inside `transform(record)`:

    ```python
    def transform(record):
        return {
            "invoice_id": record.get("id"),
            "customer_id": record.get("customer"),
            "amount_usd": (record.get("amount_due") or 0) / 100,
            "currency": (record.get("currency") or "usd").upper(),
            "status": record.get("status"),
            "created_at": record.get("created"),
        }
    ```
  </Step>
  <Step title="Preview">
    Click **Preview with sample data** to confirm the output shape against real source rows.
  </Step>
  <Step title="Save">
    Click **Save Script**.
  </Step>
</Steps>

### Notes

- Scripts are branch-specific, not shared across branches.
- If the function raises an exception, the preview and the pipeline run both fail.
- Use the Filter node for simple row-level keep/drop logic rather than returning `None` everywhere.
