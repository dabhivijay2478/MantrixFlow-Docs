---
title: CDC Setup for MySQL
description: Enable binary log and grant replication privileges. Exact MySQL commands.
---

<Warning>
**Database Admin Required**

You need root or admin privileges to perform these steps.
</Warning>

Follow these steps to enable CDC for MySQL.

<Steps>
  <Step>

### 1. Enable binary logging

Add to my.cnf or my.ini:

```ini
[mysqld]
log_bin = mysql-bin
binlog_format = ROW
```

Restart MySQL. For MySQL 8.0+, binlog_format defaults to ROW in many configurations.

  </Step>
  <Step>

### 2. Enable log_bin_trust_function_creators (if needed)

If you use stored procedures or functions:

```sql
SET GLOBAL log_bin_trust_function_creators = 1;
```

  </Step>
  <Step>

### 3. Grant replication privileges

```sql
GRANT REPLICATION SLAVE, REPLICATION CLIENT ON *.* TO 'mantrixflow'@'%';
FLUSH PRIVILEGES;
```

  </Step>
  <Step>

### 4. Verify binary log

```sql
SHOW VARIABLES LIKE 'log_bin';
SHOW VARIABLES LIKE 'binlog_format';
```

log_bin should be ON and binlog_format should be ROW.

  </Step>
</Steps>

After completing these steps, configure the MySQL source connection and run a pipeline with CDC sync mode.
